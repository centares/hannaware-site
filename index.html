PeopleTools Upgrade Services

A PeopleTools upgrade keeps PeopleSoft on Oracle support, closes security gaps and unlocks new features. Hannaware plans and runs the upgrade end to end, from assessment to go-live, with minimal downtime.

Upgrade planning

  • Assessment of your current PeopleTools release, infrastructure and customizations
  • Target version and certification review, including PeopleTools 8.63
  • Upgrade roadmap, timeline and cutover plan

Upgrade execution

  • PeopleTools upgrades from 8.55 through 8.62 using Change Assistant
  • New infrastructure built with Oracle DPKs; WebLogic, Tuxedo and JVM tuning
  • PeopleSoft Update Manager (PUM) image updates for HCM, FSCM, Campus Solutions and Interaction Hub

Go-live and after

  • Parallel upgrades at go-live to keep the outage window short
  • Post-upgrade validation, configuration and stabilization
  • Upgrades on-premises, on Oracle Cloud Infrastructure (OCI) with PeopleSoft Cloud Manager, or on AWS
